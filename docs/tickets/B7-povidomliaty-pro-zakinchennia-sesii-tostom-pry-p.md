# B7 · Повідомляти про закінчення сесії тостом при примусовому виході

| Пріоритет | Оцінка | Епік | Залежить від |
|---|---|---|---|
| **P1** | S (до пів дня) | Шлях збереження листа | B5 |

## Контекст

Коли refresh-токен протухає, інтерцептор (lib/sessionRefresh.ts:70) викликає onSessionExpired → AuthProvider робить void logout() (AuthProvider.tsx:52–54) → PrivateRoute миттєво редіректить на /login. Жодного пояснення користувач не бачить: globalErrorHandling свідомо ігнорує 401, окремого тоста немає — лікар посеред заповнення листа «просто опиняється» на сторінці входу. Втрату самих даних уже закриває чернетка з тікета B5 (форма при розмонтуванні пише незбережений стан у localStorage і пропонує відновлення після входу); цей тікет додає чесне повідомлення про причину виходу. Тост переживає редірект, бо Toaster змонтований на рівні App.

## Кроки реалізації

1. У frontend/src/context/AuthProvider.tsx додати `import toast from "react-hot-toast";` до імпортів.
2. У registerAuthHandlers замінити onSessionExpired (рядки 52–54) на:
```ts
      onSessionExpired: () => {
        toast.error(
          "Сесія закінчилася. Увійдіть, будь ласка, знову — незбережені зміни листа збережено як чернетку.",
        );
        void logout();
      },
```
3. Виконати `npm run lint` у frontend/.

## Критерії приймання

- [ ] При провалі оновлення сесії користувач бачить тост українською з поясненням перед/під час редіректу на /login.
- [ ] Тост показується один раз на подію протухання, звичайний ручний «Вийти» тоста не показує.
- [ ] Після повторного входу відкриття того самого листа пропонує відновити чернетку (поведінка з B5 не зламана).

## Ручна перевірка

> У проєкті немає тест-сьюти — перевірка виконується вручну на локальному дев-середовищі. Жодних дій проти продакшн-БД.

1. Локально: увійти, відкрити лист тестового пацієнта, внести зміни; у DevTools зіпсувати token у Local Storage і видалити refresh-cookie; натиснути «Зберегти лист» — очікується тост «Сесія закінчилася…» і редірект на /login.
2. Увійти знову, відкрити той самий лист — пропозиція відновлення чернетки зі змінами.
3. Натиснути «Вийти» вручну — редірект без тоста про сесію.
